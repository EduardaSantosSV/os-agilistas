Neste projeto, utilizei as ferramentas HTML, CSS e React para desenvolver uma aplicação web interativa da página "Os Agilistas". A seguir, estão as instruções básicas de como essas tecnologias foram aplicadas no projeto:
 - HTML
 - CSS
 - React

 Foi também utilizado algumas bibliotecas de animações e de icons, como as:
 - framer-motion
 - react-icons

__Instruções para Rodar o Código:__
Pré-requisitos:
- Node.js e npm 

Para rodar basta digitar o comando: npm run dev, em seguida ele automaticamente uma URL para o navegador, onde voc~e poderá visualizar o projeto em execução.
